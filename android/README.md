# Blade для Android

Клиент SSLim: TUN-сервис поверх TLS 1.3. Адрес сервера, порт, SNI и секрет
не зашиты в приложение — они хранятся в профилях, которые пользователь
создаёт сам или импортирует по ссылке `sslim://`.

## Возможности

- Список профилей с выбором активного; все поля редактируются: название,
  адрес, порт, TLS server name, секрет (base64), свой CA (PEM) вместо системных.
- Импорт: клик по ссылке `sslim://host:port?sni=...&k=...&n=...`
  (открывает Blade из браузера или чата), вставка из буфера, ручной ввод,
  заполнение формы из ссылки внутри редактора.
- Переподключение с задержкой 0,25 с → 30 с; keepalive-пинги каждые 3 с
  (RTT видно на главном экране).
- Исходящий сокет защищён `protect()`, чтобы не зацикливаться в собственный TUN.

## Сборка

Нужны Android SDK (build-tools 35.0.0, platforms android-35) и JDK 17. Gradle не используется.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 `
  -Sdk C:\path\to\android-sdk `
  -Jdk C:\path\to\jdk-17
```

Готовый подписанный APK появится в `build\Blade.apk` (keystore создаётся
автоматически, пароль хранилища `android` — замените на свой перед раздачей).

## Требования

- Android 10 (API 29) или новее.
- Разрешение VPN выдаётся системой при первом подключении.
- Сервер SSLim (подкоманда `sslim server`) с TLS-сертификатом, который
  доверяет устройство, либо свой CA в профиле.
