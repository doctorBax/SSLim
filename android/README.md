# Blade для Android

Клиент SSLim: TUN-сервис поверх TLS 1.3. Адрес сервера, порт, SNI и секрет
не зашиты в приложение — они хранятся в профилях, которые пользователь
создаёт сам или импортирует по ссылке `sslim://`.

## Возможности

- Список профилей с выбором активного; все поля редактируются: название,
  адрес, порт, TLS server name, секрет (base64), свой CA (PEM) вместо системных.
- Импорт: клик по ссылке `sslim://host:port?sni=...&k=...&n=...`
  (открывает Blade из браузера или чата), вставка из буфера, ручной ввод,
  заполнение формы из ссылки внутри редактора.
- Переподключение с задержкой 0,25 с → 30 с; keepalive-пинги каждые 3 с
  (RTT видно на главном экране).
- Исходящий сокет защищён `protect()`, чтобы не зацикливаться в собственный TUN.

## Экран настроек

- **Профили**: выбор активного сервера, добавление по ссылке, редактирование и удаление. Прежний `profiles.json` сохраняется.
- **Настройки приложения**: автопереподключение, DNS (Cloudflare, Google, Quad9), журнал производительности `BladePerf`.
- **Kill switch (Android lockdown)**: в Blade откройте «Настройки → Настройки приложения → Kill switch → Настройки VPN». Найдите Blade и включите **«Постоянная VPN»** и **«Блокировать подключения без VPN»**. Только оба системных переключателя обеспечивают блокировку трафика при обрыве, остановке приложения или перезагрузке. Само приложение не может переключить их программно. При активном lockdown ручное отключение Blade также блокирует интернет.
- Для перезапуска VPN системой Blade может читать активный профиль при запуске службы без параметров. Для смены DNS требуется переподключение.
- Если включили системный kill switch, перед удалением APK или переключением на другое VPN-приложение отключите lockdown в настройках Android.

## Оформление (Android 0.6.0-dev)

«Настройки → Оформление»: системная, тёмная и светлая темы; акценты Blade Mint, Arctic Blue, Soft Lavender, Warm Amber и собственный HSV/HEX; пять независимых анимаций центральной панели (Orbit, Aurora, Data Stream, Spectrum, Crystal); круглая или квадратная кнопка; тактильный отклик. Большая панель по-прежнему подключает/отключает VPN, кнопка остаётся со стрелкой.

Предпросмотр на экране оформления интерактивен и **никогда не запускает VPN**: нажатие имитирует переключение состояния. Все изменения отображаются сразу и сохраняются в локальных настройках. Текущие профили серверов остаются нетронутыми.

«Настройки → Настройки приложения → Проверить обновления» выполняет **только ручной** HTTPS-запрос к последнему GitHub Release и сравнивает версию. Blade не запускает проверки в фоне, не скачивает APK, не устанавливает обновления и не требует разрешения на установку сторонних приложений. Если найден более новый Android APK, приложение открывает страницу релиза по явному нажатию.

Ветка 0.6.0-dev предназначена для тестирования. **Не является опубликованным релизом**.

## Сборка

Нужны Android SDK (build-tools 35.0.0, platforms android-35) и JDK 17. Gradle не используется.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 `
  -Sdk C:\path\to\android-sdk `
  -Jdk C:\path\to\jdk-17
```

Готовый подписанный APK появится в `build\Blade.apk` (keystore создаётся
автоматически, пароль хранилища `android` — замените на свой перед раздачей).

## Требования

- Android 10 (API 29) или новее.
- Разрешение VPN выдаётся системой при первом подключении.
- Сервер SSLim (подкоманда `sslim server`) с TLS-сертификатом, который
  доверяет устройство, либо свой CA в профиле.
