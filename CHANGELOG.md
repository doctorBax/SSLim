# История версий

## v0.1.0

Первый выпуск Linux-транспорта.

- Клиент и сервер отправляют до 32 уже доступных пакетов одним вызовом записи в TLS-поток. Формат кадров сохранён.
- При заполнении очереди Linux TUN приостанавливает чтение и возобновляет его после извлечения пакетов.
- При остановке одного направления клиент завершает второе до закрытия туннеля.
- Локальная проверка TLS охватывает одиночный пакет и пачку из 32 пакетов.
